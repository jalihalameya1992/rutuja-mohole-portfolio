Reliance Smart Bazaar

An identity and signage refresh across 1,000+ Reliance Smart Bazaar stores.

Elephant Design, Pune

Role
Identity Design + Visual System Guidelines
Scale
1,000+ retail stores, bilingual signage

Task at hand

Refresh the identity and signage for Reliance Smart Bazaar so it feels like one brand across 1,000+ stores. The goals were better legibility, stronger recognition and a flexible visual system that works in store and online, without losing the equity the brand already had.

Challenge

Build an identity that adapts to different store formats, buildings and regional regulations. Make it more visible and readable while keeping it familiar, and create one signage framework that handles both English and regional-language logos. It has to be flexible enough for thousands of real storefronts and still look consistent.

Brand system overview, animated.

07 / 09 the system

Design System

Less a redesign, more a tightening. Same identity, just sharper, and built to hold up on a storefront in any city, in any script.

A sharper logo We sharpened the existing logo with better proportions, spacing and balance, so it's easier to read without changing what it is.
Signage that adapts A modular signage system adjusts to different storefront sizes and formats and still looks like the same brand.
The blue band A strong blue band across the fascia is the constant, so you recognise a store straight away.
Two scripts, one system Typography, proportions and hierarchy set across English and regional scripts, worked out with a type designer who specialises in regional scripts.
One system, every touchpoint Guidelines cover facades, storefronts, vehicles, packaging, digital media and in-store communication, so every touchpoint matches.
